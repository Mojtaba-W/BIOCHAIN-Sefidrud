# BIOCHAIN-Sefidrud
Interactive Scientific Visualization

Nature-Inspired Intelligence for Watershed Management

An interactive scientific visualization exploring how watershed processes can be connected to bio-inspired optimization concepts, including Ant Colony Optimization (ACO) and Particle Swarm Optimization (PSO), with satellite/data-driven decision support.

## Run locally

Open `index.html` in a modern browser (Chrome, Edge, Firefox, or Safari).

## GitHub Pages

This repository is designed for GitHub Pages. Publish from the `main` branch and the repository root (`/`).

## Notes

This is a conceptual scientific visualization rather than a calibrated hydrological or sediment-transport model. Numerical values and process representations should be interpreted in the context stated inside the visualization.
